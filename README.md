# Карго AAA168 — сайт

Одностраничный сайт ООО «И ЛУ ФА»: доставка грузов из Китая в Россию.

- Все тексты, контакты, сроки и тарифы — в `content.js`.
- Видео — `assets/video/` (сжатые, с превью .jpg), скриншоты отзывов — `assets/reviews/`.
- Запуск локально: открыть `index.html` в браузере или `python -m http.server 8080`.
