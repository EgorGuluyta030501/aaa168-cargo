# Карго AAA168 — сайт

Одностраничный сайт ООО «И ЛУ ФА»: доставка грузов из Китая в Россию.

- Все тексты, контакты, сроки и тарифы — в `content.js`.
- Видео — `assets/video/` (сжатые, с превью .jpg), скриншоты отзывов — `assets/reviews/`.
- Запуск локально: открыть `index.html` в браузере или `python -m http.server 8080`.

## Поисковики и законы (РФ / РБ)

- **Заявки** уходят в личный Telegram менеджера (`contacts.manager` в content.js). Пока поле пустое — в WhatsApp.
  Сайт не спрашивает имя и телефон и ничего не хранит, поэтому не собирает персональные данные.
- **Шрифт** лежит в `assets/fonts` — сайт не обращается к Google и другим сторонним серверам.
- **Политика конфиденциальности** — `privacy.html`. Подключите Метрику или форму на сервер — обновите текст.
- **Для Яндекса** `tools/build.py` «впекает» тексты из content.js в index.html и пишет sitemap.xml и robots.txt.
  Запускается сам при коммите; вручную: `python tools/build.py`.
- **После покупки домена** поменяйте `seo.url` в content.js и впишите код из Яндекс Вебмастера в `seo.yandexVerification`.
